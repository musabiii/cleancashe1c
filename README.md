# CleanCache1C

Показывает список информационных баз 1С и размер их кэша. Отмеченные базы можно очистить.

Программа — один файл `CleanCache1C.exe` (около 30 КБ) под .NET Framework 4.8. Она запускается простым копированием на любую Windows 10/11 и Windows Server 2012 R2+, в том числе по RDP. Ничего устанавливать не нужно.

## Откуда берутся данные

| Что | Где |
|---|---|
| Список баз (имя, группа, строка подключения, `ID`) | `%APPDATA%\1C\1CEStart\ibases.v8i` и общие списки из `CommonInfoBases=` в `1cestart.cfg` (пользовательском и `%ProgramData%\1C\1CEStart`) |
| Кэш базы — колонка «Кэш (Local)» | `%LOCALAPPDATA%\1C\1cv8\<ID>` (и `1cv82` для 8.2) |
| Настройки пользователя — колонка «Настройки (Roaming)» | `%APPDATA%\1C\1cv8\<ID>` |

Если в кэше есть папка, а базы с таким ID в списке нет, она показывается серой строкой «‹нет в списке баз›». Обычно это остатки удалённых баз, их можно смело чистить.

## Как пользоваться

- **Профиль.** По умолчанию выбран текущий пользователь. Профили других пользователей сервера появятся в списке, если запустить программу от имени администратора.
- **Сортировка.** Щелчок по заголовку колонки. После подсчёта список сортируется по размеру кэша.
- **Поиск.** Ищет по имени, группе, строке подключения и ID.
- **Двойной щелчок по строке** открывает папку кэша. Через правую кнопку можно открыть папку настроек или скопировать ID.
- **Очистка.** Отметьте базы галочками и нажмите «Очистить кэш отмеченных». Настройки пользователя (Roaming) удаляются, только если включён соответствующий флажок.
  - Перед удалением программа предупреждает о запущенных процессах 1С. Файлы открытых баз заняты и не удалятся.
  - Кэш 1С пересоздаёт сама при следующем запуске базы.
- Пароли в строке подключения (`Pwd=`) скрыты. Строку `AdditionalParameters` программа не показывает.

## Сборка

```bash
build.bat
```

Иконка `assets\app.ico` уже лежит в репозитории. Чтобы её перерисовать, запусти `tools\make-icon.ps1` в PowerShell 7. Скрипт рисует ICO на 16–256 px и картинку для просмотра `assets\icon-preview.png`.

Результат: `dist\CleanCache1C.exe`. Нужен .NET SDK 6+ (reference assemblies для net48 подтянутся из NuGet).
